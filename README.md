
# PureNest Cleaning — Landing Page Demo

A clean, responsive landing page concept for a fictional
residential cleaning business.

## Live Demo

## Live Demo

## Features

- Responsive layout for desktop and mobile
- Service and pricing sections
- Contact section with a demo email link
- Privacy Policy and Terms of Service pages
- Simple navigation and clean design

## Built With

- HTML5
- CSS3

## Project Purpose

This project was created as a web design portfolio example.
PureNest Cleaning is a fictional business.

All prices, business details, and legal pages are illustrative
and should be customized before use by a real business.
